# GroupDiive Demo Script

1. Start the app with `streamlit run app.py` and open the local address it prints.
2. Point out the GroupDiive header, choose a city, and show the Buyer/Dealer switch.
3. Search the local demo catalog for a make or model. Show the separate ex-showroom and indicative on-road prices, and note that sample data must be verified.
4. Add two variants to Compare. Show that missing specifications are labeled Unavailable.
5. Open Buying Groups and explain that member counts come from the local database. Use the join or start form; joining is not a commitment to buy.
6. Open Dealer Offers and compare each itemized amount. Explain that seeded offers are demo data and new portal submissions are unverified unless explicitly marked verified.
7. Ask the AI helper a question about the selected car or group quote. It uses only the supplied local data. If Ollama is off, show the unavailable message; the rest of the app still works.

Do not present demo prices, dealer records, groups, or seeded member counts as live market information.
